## Ограничения продукта

**Аудио.** Аудиофайлов и URL нет ни в архивах, ни в коде. Плеер подключён к `HTMLAudioElement` и не имитирует звук. Нужны пять записей или их публичные URL и право использования; подключаются в `audioSrc` в `assets/js/site-data.js`. Истории: «Дом, где тебя ждут», «Наше воскресенье», «Наш класс», «До утра», «Папина пластинка».

**Приём заявок.** Backend и CRM отсутствуют. Посетитель готовит и копирует сообщение, затем самостоятельно отправляет его в https://t.me/vivo_support. Успешная доставка сайтом не заявляется; тестовых сообщений менеджеру не отправляли. Клиентских секретов нет.

**Юридические тексты** совпадают с исходным экспортом (проверено по нормализованному тексту main). Правовая оценка не выполнялась, условия не переписывались.

## Техдолг, который стоит обсудить с разработчиками

CSS разложен на семь файлов, подключаемых строго по порядку: `hero.css` → `sections.css` → `restoration.css` → `refinement.css` → `round-two.css` → `final-pass.css` → `vinyl-polish.css`, со строками `?v=` в ссылках. Это накопленные слои правок: каждый следующий файл переопределяет предыдущие. Работает корректно, но любая правка требует понимать весь каскад. Консолидация не выполнялась — это рефакторинг, а не подготовка к передаче, и его стоит планировать отдельно.
